"Mzizi" names more than one thing, and the pieces have different operators and very
different maturity. This page draws the map. The language is the subject; the toolchain,
the components and the platform support it.

## The repositories

All in the [`mzizi-dev`](https://github.com/mzizi-dev) org.

<CardGroup cols={2}>
  <Card title="mzizi" icon="sprout" href="https://github.com/mzizi-dev/mzizi">
    **The language.** The `mz` compiler, the RFCs, the nine primitives, the benchmark
    harness and the pilot results. Rust, Apache-2.0, public.

    _Phase 0 prototype front end. Two pilots run, no advantage shown._

  </Card>
  <Card title="mzizi-registry" icon="library" href="https://github.com/mzizi-dev/mzizi-registry">
    **The component registry, brand system and DNA-helix architecture.** 577 components in
    `registry.json` and the files beside it, the 21-family palette, and the Rust crates
    that [Mzizi Roots](/roots/overview) grows from. **No database**: its files are the data
    layer.

    _Its files reach clients through the API and the MCP server. Its own Worker still runs
    on a `workers.dev` address, where the per-component portal pages that
    `mzizi.dev/components/<name>` redirects to are served._

  </Card>
  <Card title="mzizi-api-gateway" icon="server" href="https://github.com/mzizi-dev/mzizi-api-gateway">
    **`api.mzizi.dev`.** A Hono Cloudflare Worker in TypeScript that serves the registry's
    files, generated at a pinned registry commit and bundled at build time. No origin, no
    database.

    _Live on `api.mzizi.dev` since 29 September 2026. See [the API gateway](/platform/api-gateway)._

  </Card>
  <Card title="mzizi-site" icon="globe" href="https://github.com/mzizi-dev/mzizi-site">
    **`mzizi.dev`.** Static Astro. It leads with the language; the components live further
    down, at `mzizi.dev/components`.

    _Live._

  </Card>
  <Card title="mzizi-docs" icon="book-open" href="https://github.com/mzizi-dev/mzizi-docs">
    **`docs.mzizi.dev`**, this site. Mintlify. The one home of Mzizi's documentation, with a
    public docs MCP server at `docs.mzizi.dev/mcp`.

    _Live._

  </Card>
  <Card title="mzizi-console" icon="layout-dashboard" href="https://github.com/mzizi-dev/mzizi-console">
    **`app.mzizi.dev`.** Astro chrome with Rust islands over the registry API, behind
    AuthKit sign-in. **Run under Nyuchi.** The only part of Mzizi with a database.

    _Live. See [the console](/console)._

  </Card>
</CardGroup>

The org also holds a private tooling repository, `mzizi-dev/agent-tools`. It builds the MCP
server (`mzizi-mcp`, at `mcp.mzizi.dev`), the CLI and the skills bundle, which are
documented under [the toolchain](/toolchain/overview) by their published npm packages.
`mzizi-roadmap` is archived; the plans live in
[`design/ROADMAP.md`](https://github.com/mzizi-dev/mzizi/blob/main/design/ROADMAP.md).

## The addresses

Checked 30 September 2026 with an HTTPS request to each.

| Address          | Served by                                        | Answers                                         |
| ---------------- | ------------------------------------------------ | ----------------------------------------------- |
| `mzizi.dev`      | `mzizi-site`                                     | 200                                             |
| `api.mzizi.dev`  | `mzizi-api-gateway`                              | 200 on `/v1`; a JSON 404 on the bare host       |
| `mcp.mzizi.dev`  | `mzizi-mcp`, from the private tooling repository | 200 on `/mcp` to an MCP client, with no sign-in |
| `app.mzizi.dev`  | `mzizi-console`, run under Nyuchi                | 200, behind sign-in                             |
| `docs.mzizi.dev` | `mzizi-docs`, on Mintlify                        | 200                                             |

Addresses move. Check one before you repeat it. The old Mzizi path on `docs.bundu.org`
returns 404; do not link it.

## Who operates what

This line decides which organisation's clock each piece runs on.

|                                                                                 | Operated by |
| ------------------------------------------------------------------------------- | ----------- |
| The language, its toolchain, the registry, the design system, the docs, the API | **Mzizi**   |
| The console, Fundi, paid plans, billing and the other revenue products          | **Nyuchi**  |

Copyright notices name the **Bundu Foundation** as the parent copyright holder. Mzizi is
not a separate legal entity. There is one ecosystem, the Bundu ecosystem, and Mzizi, nyuchi,
mukoko and the other brands sit inside it.

### Contact

For anything about Mzizi that is not a security report, write to
[`support@bundu.org`](mailto:support@bundu.org): questions, the docs, the API, the MCP server,
the CLI and the components. To report a problem with a docs page, you can also use the
`docs_submit_feedback` tool on [the MCP server](/toolchain/mcp).

### Reporting a security problem

| For                                                                   | Contact               |
| --------------------------------------------------------------------- | --------------------- |
| The console at `app.mzizi.dev`                                        | `security@nyuchi.com` |
| Everything else Mzizi, including these docs, the API and the language | `security@bundu.org`  |

Where a repository has GitHub private vulnerability reporting switched on, you can use that
instead.

## The language, and what supports it

<CardGroup cols={2}>
  <Card title="The language" icon="flask-conical" href="/status">
    A programming language, and a Phase 0 research prototype. Phase 0 builds it, measured
    against the best existing language for each kind of task; two small pilots have run, with no
    advantage shown. Nothing built with it runs anywhere yet.
  </Card>
  <Card title="The components" icon="library" href="/roots/overview">
    Shipping and installable. Rust components are becoming Mzizi Roots and lead; the React
    components keep working as the React build.
  </Card>
</CardGroup>

The components are built to support the language: its UI layer, and where its output is
meant to land. They also supply the ground truth for the benchmark's UI tasks: the nine
[primitives](/primitives) are hand ports of registry components whose React and Rust
implementations serve as references. That is one of their jobs, not the relationship's
whole.

## Where the docs went

Links to older locations are still in circulation. The registry used to run its own docs
site; that is retired, and `GET https://api.mzizi.dev/v1/docs` answers **410 Gone**. The
Mzizi pages that lived in nyuchi's engineering docs moved here. This site is the one home of
Mzizi's documentation.
